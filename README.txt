GitHub Pages:
1. Dateien in ein GitHub-Repository hochladen.
2. GitHub -> Settings -> Pages.
3. "Deploy from a branch" auswählen.
4. Branch "main" und Ordner "/ (root)" auswählen.
5. Speichern.

Wichtig:
Die Regeltexte und Shop-Preise sind Platzhalter und sollten vor Veröffentlichung an die tatsächlichen FloSMP-Regeln und Angebote angepasst werden.
